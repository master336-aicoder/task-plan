# 任务计划系统需求文档

## 1. 概述

参照 Apache DolphinScheduler 设计模式，构建一个任务计划工具箱系统，提供工作流编排、任务调度、执行监控等核心功能。

## 5. 技术架构

### 5.1 后端技术栈

- **语言**: Java 21
- **框架**: Spring Boot 3.2.x
- **数据库**: MySQL 8.0+
- **ORM**: Spring Data JPA
- **调度引擎**: Quartz
- **构建工具**: Maven

### 5.2 前端技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI组件**: Element Plus
- **路由**: Vue Router

### 5.3 核心实体

| 实体 | 说明 |
| :--- | :--- |
| Project | 项目实体 |
| ProcessDefinition | 工作流定义 |
| TaskDefinition | 任务定义 |
| ProcessSchedule | 调度配置 |
| ProcessInstance | 工作流实例 |
| TaskInstance | 任务实例 |
| Datasource | 数据源配置 |
| ServerNode | 服务器节点 |
| FileResource | 文件资源 |
| ClusterConfig | 集群配置 |
| TaskTypeConfig | 任务类型配置 |
