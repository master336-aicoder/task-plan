## 1. 系统概述

任务计划工具箱是一个企业级任务计划管理系统，参照 Apache DolphinScheduler 设计，支持：

- **可视化工作流编排**：通过拖拽方式设计复杂的任务依赖关系
- **多种任务类型**：支持 Shell、Python、Java、SQL、HTTP 等任务类型
- **灵活调度配置**：支持 Cron 表达式、固定间隔等调度方式
- **完整权限管理**：基于角色的访问控制（RBAC）

### 系统架构

```
前端 (Vue 3) ←→ API网关 ←→ 后端服务 (Spring Boot) ←→ MySQL数据库
                                              ←→ 文件存储
                                              ←→ Quartz调度引擎
```

### 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue | 3.2.x |
| 前端 | Element Plus | 2.2.x |
| 后端 | Spring Boot | 3.2.x |
| 数据库 | MySQL | 8.0+ |
| 调度 | Quartz | 2.3.x |

## 2. 快速入门

### 2.1 环境准备

#### 2.1.1 硬件要求

| 配置项 | 最低配置 | 推荐配置 |
|--------|----------|----------|
| CPU | 2核 | 4核 |
| 内存 | 4GB | 8GB |
| 磁盘 | 50GB | 100GB |

#### 2.1.2 软件要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | Java 开发环境 |
| Node.js | 18+ | 前端开发环境 |
| MySQL | 8.0+ | 数据库 |

### 2.2 安装部署

#### 2.2.1 数据库配置

1. 创建数据库：
```sql
CREATE DATABASE task_plan_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. 创建用户并授权：
```sql
CREATE USER 'taskplan'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON task_plan_db.* TO 'taskplan'@'localhost';
FLUSH PRIVILEGES;
```

#### 2.2.2 后端启动

```bash
# 进入后端目录
cd backend

# 编译运行
mvn spring-boot:run
```

服务启动后访问：http://localhost:8080

#### 2.2.3 前端启动

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端启动后访问：http://localhost:3000

### 2.3 登录系统

打开浏览器访问 http://localhost:3000，使用默认账号登录：

- **用户名**：admin
- **密码**：123456

## 3. 工作流设计

### 3.1 创建工作流

1. 点击左侧菜单「工作流管理」→「工作流列表」
2. 点击「创建工作流」按钮
3. 填写工作流名称和描述
4. 点击「设计」进入工作流设计器

### 3.2 设计工作流

#### 3.2.1 添加任务节点

1. 在左侧任务类型面板选择任务类型（如 Shell脚本、Python脚本等）
2. 拖拽任务到画布上
3. 双击任务节点编辑详细配置

#### 3.2.2 配置任务连接

1. 点击源任务节点的输出端口（右侧圆点）
2. 拖拽到目标任务节点的输入端口（左侧圆点）
3. 连线表示任务执行顺序

#### 3.2.3 任务配置说明

不同任务类型有不同的配置项：

| 任务类型 | 主要配置项 |
|----------|------------|
| Shell脚本 | 脚本内容或脚本文件 |
| Python脚本 | Python代码或脚本文件 |
| Java | 主类名、参数 |
| SQL | 数据源、SQL语句 |
| HTTP | URL、方法、请求体 |

### 3.3 保存和发布

1. 点击「保存」按钮保存工作流（草稿状态）
2. 点击「发布」按钮将工作流变为可执行状态
3. 发布后的工作流才能被调度执行

## 4. 任务管理

### 4.1 任务定义管理

1. 点击左侧菜单「资源管理」→「任务定义」
2. 可以查看、创建、编辑、删除任务定义
3. 任务定义可以被多个工作流引用

1. 点击「创建任务」按钮
2. 填写任务名称
3. 选择任务类型

5. 点击「保存」

### 4.3 任务类型说明

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| SHELL | Shell脚本任务 | 执行Linux命令或脚本 |
| PYTHON | Python脚本任务 | 执行Python脚本 |

| HTTP | HTTP请求任务 | 调用REST API |

| HIVE | Hive任务 | 执行Hive SQL |

## 5. 调度管理

### 5.1 创建调度计划

1. 点击左侧菜单「调度中心」→「调度管理」
2. 点击「创建调度」按钮
3. 选择要调度的工作流
4. 配置Cron表达式
5. 设置开始时间和结束时间（可选）
6. 点击「保存」

### 5.2 Cron表达式配置

系统提供图形化的Cron编辑器：

1. 点击Cron输入框旁的「编辑」按钮
2. 在弹出的编辑器中选择时间规则
3. 系统自动生成Cron表达式

**Cron表达式格式**（6字段）：
```
秒 分 时 日 月 周
```

**常用示例**：
| 表达式 | 说明 |
|--------|------|
| `0 0 2 * * ?` | 每天凌晨2点执行 |
| `0 0/30 * * * ?` | 每30分钟执行 |
| `0 0 12 * * MON-FRI` | 工作日中午12点执行 |
| `0 0 0 1 * ?` | 每月1日凌晨执行 |

### 5.3 调度状态管理

| 状态 | 说明 | 操作 |
|------|------|------|
| 启用 | 调度正常运行 | 可禁用 |
| 禁用 | 调度暂停执行 | 可启用 |

2. 点击「上传文件」按钮
3. 选择本地文件
4. 点击「确定」上传

1. 在文件列表中找到目标文件

| 文件类型 | 扩展名 | 支持编辑 |
|----------|--------|----------|

| Java文件 | .java | 是 |
| HTML文件 | .html | 是 |

## 7. 系统管理

### 7.1 用户管理

#### 7.1.1 创建用户

1. 点击左侧菜单「系统管理」→「用户管理」
2. 点击「创建用户」按钮
3. 填写用户名、密码、真实姓名等信息
4. 点击「保存」

#### 7.1.2 分配角色

1. 在用户列表中找到目标用户
2. 点击「分配角色」按钮
3. 在弹出的对话框中选择角色
4. 点击「确定」

### 7.2 角色管理

4. 点击「保存」

#### 7.2.2 权限配置

角色通过菜单关联来控制权限：
- 超级管理员：拥有所有权限
- 普通用户：根据分配的角色获得相应权限

## 8. 常见问题

### 8.1 登录问题

**问题**：登录失败，提示"用户名或密码错误"

**解决**：
1. 检查用户名和密码是否正确（默认：admin/123456）
2. 检查后端服务是否正常运行
3. 检查数据库连接是否正常

### 8.2 文件上传问题

**问题**：文件上传失败

**解决**：
1. 检查文件大小是否超过限制（默认100MB）
2. 检查文件类型是否在允许列表中
3. 检查上传目录权限是否正确

### 8.3 工作流执行问题

**问题**：工作流无法启动

**解决**：
1. 检查工作流是否已发布
2. 检查工作流是否有任务节点
3. 检查任务配置是否正确

### 8.4 调度问题

**问题**：调度不执行

**解决**：
1. 检查调度是否已启用
2. 检查Cron表达式是否正确
3. 检查系统时间是否正确

### 8.5 权限问题

**问题**：无法访问某些页面

**解决**：
1. 检查用户角色是否正确分配
2. 检查角色是否有相应菜单权限
3. 联系管理员获取权限
