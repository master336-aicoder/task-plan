# 任务计划工具箱 - 开发计划

> **For agentic workers:** 本计划采用细粒度任务分解，每个任务均可独立执行并测试。

## 项目概述

### 目标
构建一个功能完善的企业级任务计划管理系统，支持任务创建、调度、执行、监控与告警等全生命周期管理。

### 架构
- 前后端分离架构
- RESTful API 设计
- 前端：Vue3 + TypeScript + Vite + Element Plus
- 后端：Spring Boot + Quartz + Redis + Flowable

### 技术栈
**前端：**
- Vue 3.2.45
- Vite 4.0.1
- Element Plus 2.2.26
- TypeScript 4.9.4
- Pinia 2.0.28
- Vue Router 4.1.6
- UnoCSS 0.58.9
- Chart.js 4.4.0

**后端：**
- Spring Boot 2.7.14
- Quartz 2.3.2 (调度引擎)
- Redis 5.0+ (缓存/分布式锁)
- Flowable (工作流)
- Spring Boot Admin (应用监控)
- Lombok

## 代码规范

### 命名规范
- **Java**: 类名 PascalCase，方法名 camelCase，变量名 camelCase
- **TypeScript**: 接口名 Ixxx，类名 PascalCase，方法/变量 camelCase
- **文件**: 小写字母，单词间用连字符或下划线

### 代码风格
- 缩进使用 4 空格
- 每行不超过 120 字符
- 使用 Lombok 减少样板代码
- 方法注释使用 Javadoc 格式

### Git 提交规范
```
feat: 新增功能
fix: 修复bug
docs: 更新文档
style: 代码格式调整
refactor: 重构代码
test: 添加测试
chore: 构建/工具更新
```
